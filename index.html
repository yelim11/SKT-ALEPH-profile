01

문제를 단계적으로 해결해요

복잡한 문제도 작은 단위로 나누어 하나씩 확인합니다.

상황
대학 팀 프로젝트에서 게임을 제작하며 기능을 연결하는 과정에서 문제 상황이 발생했습니다.
행동
문제를 기능별로 나누어 확인하고, 필요한 부분을 수정한 뒤 직접 실행해 결과를 확인했습니다.
결과
문제를 한 번에 추측하기보다 원인을 좁혀가며 해결하는 습관을 갖게 되었습니다.
02

직접 만들며 배우는 걸 좋아해요

설명만 읽기보다 직접 구현하고 실행하면서 이해합니다.

상황
대학 팀 프로젝트에서 Unity를 이용해 1인 게임을 제작해야 했습니다.
행동
필요한 기능을 직접 구현하고 실행 결과를 확인하면서 프로젝트를 완성해 나갔습니다.
결과
아이디어에 그치지 않고 실제로 실행 가능한 게임 프로젝트를 결과물로 남겼습니다.
03

기록하고 정리하는 습관이 있어요

작업 내용을 문서와 저장소에 남겨 과정을 다시 확인할 수 있게 합니다.

상황
팀 프로젝트에서 게임 파일과 작업 내용을 관리할 필요가 있었습니다.
행동
GitHub 저장소와 프로젝트 문서를 활용해 작업 결과와 관련 자료를 정리했습니다.
결과
Unity 프로젝트의 Assets, Packages, ProjectSettings와 작업 문서를 포함한 결과물을 남겼습니다.
