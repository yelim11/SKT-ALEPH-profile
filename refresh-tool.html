기록 갱신 장치

리추얼·출석·과제 목록 CSV를 읽어 숫자와 능력별 문단 후보를 다시 만드는 로컬 Python 장치입니다. AI API를 호출하지 않기 때문에 같은 입력에서는 같은 결과가 나옵니다.

실행 방법

  1. inputs/ 폴더의 CSV를 최신 기록으로 바꿉니다.
  2. python run.py를 실행합니다.
  3. outputs/last_result.json과 paragraph_candidates.md를 확인합니다.

재현성 검사

python verify_reproducible.py를 실행하면 새 임시 폴더 두 곳에서 같은 입력을 각각 실행하고 전체 출력의 SHA-256을 비교합니다.

현재 제공 입력으로 두 번 실행한 결과: PASS

두 실행의 출력 해시: aaca1ac7f3c74376e2c7c94443c913530bc8fab2209b2a26978268211f07234c

현재 입력과 원칙

리추얼 원본은 2026-08-11부터 2026-09-11까지 23일이며, 공개 자기소개 후보로 구조화한 장면은 7개입니다. 원본 기록일 수와 문단 후보 수를 따로 계산합니다.

확인되지 않은 숫자는 추정하지 않습니다. 13주 출석 원본은 현재 제공 자료에서 찾지 못해 attendance.csv를 빈 상태로 두었고, 원본을 넣으면 그때 다시 계산됩니다. 문단 후보에는 날짜와 출처가 붙고, 승인 목록에 있는 날짜만 사이트 후보로 출력됩니다.
